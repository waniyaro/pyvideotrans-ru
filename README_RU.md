# pyVideoTrans (Русская версия + Модули улучшения звука и Sber GigaAM)

## 🛠️ Что добавлено в программу

### 1. Полная русская локализация
- Переведено **1170+** элементов интерфейса: главное окно, все меню, настройки, тултипы и диалоги.
- Интерфейс автоматически определяет русский язык системы.

### 2. «Мастер обработки звука и очистки» (Новый инструмент)
В главном окне перейдите в меню **«Инструменты» (&Tools) → «Мастер обработки звука и очистки»**:
- **Улучшение голоса:**
  - *High-pass 80 Гц:* убирает гул стола, микрофона и кондиционера.
  - *FFT-шумодав:* убирает шипение без искажения голоса (уровни: Легкий, Средний, Сильный).
  - *Эквалайзер четкости:* подъем частот разборчивости речи (3.2 кГц) и срез глухоты (350 Гц).
  - *Нормализация громкости:* вещательный стандарт EBU R128 (-16 LUFS) — выравнивает громкость шепота и криков.
- **Быстрая обрезка (Lossless Trim):**
  - Вырезка фрагментов аудио/видео по времени (Start — End) мгновенно без перекодирования.
- **Очистка текста и субтитров:**
  - Удаление слов-паразитов («эээ», «ммм», «типа», «как бы», «короче»).
  - Удаление заиканий и повторов слов.
  - Кнопка **«Распознать русскую речь (Sber GigaAM)»** — транскрибирует выбранное аудио/видео моделью Сбера без галлюцинаций Whisper и сразу сохраняет субтитры `.srt`.

### 3. Sber GigaAM в основном окне
В выпадающем списке каналов распознавания речи (ASR) добавлен пункт **`Sber GigaAM (Русский)`**.

## 💻 Использование через консоль (CLI)

```bash
# Активировать окружение (если нужно):
cd /Users/waniyaro/.gemini/antigravity/scratch/pyvideotrans

# 1. Транскрибировать аудио моделью GigaAM Сбера с созданием субтитров .srt:
.venv/bin/python videotrans/util/voice_toolkit.py transcribe -i audio.mp3 -o subs.srt

# 2. Улучшить голос и убрать шум из видео/аудио:
.venv/bin/python videotrans/util/voice_toolkit.py enhance -i input.mp3 -o enhanced.mp3

# 3. Вырезать кусок с 10-й секунды до 1:30 без потери качества:
.venv/bin/python videotrans/util/voice_toolkit.py trim -i video.mp4 -o clip.mp4 -s 00:00:10 -e 00:01:30

# 4. Очистить текст от слов-паразитов:
.venv/bin/python videotrans/util/voice_toolkit.py clean-text -t "Ну, эээ... короче мы мы записали видео, типа отлично!"

# 5. Очистить существующий файл субтитров .srt:
.venv/bin/python videotrans/util/voice_toolkit.py clean-srt -i raw.srt -o clean.srt
```

## 🔌 Подключение к ИИ (MCP-сервер)

Файл `audio_voice_mcp.py` можно прописать в конфиг любого ИИ-ассистента (Claude Desktop, Cursor, Antigravity):
```json
{
  "mcpServers": {
    "voice-toolkit": {
      "command": "/Users/waniyaro/.gemini/antigravity/scratch/pyvideotrans/.venv/bin/python",
      "args": ["/Users/waniyaro/.gemini/antigravity/scratch/pyvideotrans/audio_voice_mcp.py"]
    }
  }
}
```
Инструменты сервера:
- `enhance_voice` — шумоподавление и улучшение разборчивости голоса.
- `trim_media` — обрезка аудио/видео.
- `clean_transcript_text` — очистка текста от мусорных слов.
- `clean_srt_subtitles` — очистка субтитров.
- `transcribe_audio_gigaam` — транскрибация через Сбер GigaAM.
